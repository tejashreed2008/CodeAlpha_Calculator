# 🧮 Calculator

A simple calculator application that performs basic arithmetic operations with a clean and user-friendly interface.

## ✨ Features
- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- ✅ Easy to use
- ⚡ Fast and accurate calculations

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript

## 🚀 How to Use
1. Clone this repository.
2. Open the `index.html` file in your browser.
3. Enter two numbers.
4. Select an operation and view the result.
